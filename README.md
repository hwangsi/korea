# Conflict: Korea 리메이크

SSI의 1992년 DOS 작전급 워게임 **Conflict: Korea – The First Year 1950-51** (디자이너 Norm Koger)을
웹 브라우저용으로 다시 만드는 개인 프로젝트입니다. 규칙은 원작 실행 파일을 역공학해 **원작 코드 그대로** 옮기고,
화면·조작·편의 기능은 한국어와 마우스 중심으로 새로 만듭니다.

- 실행 방법과 폴더 구조: [`remake/README.md`](remake/README.md)
- 작업을 이어갈 때(새 PC, 새 AI 세션): [`remake/docs/HANDOFF.md`](remake/docs/HANDOFF.md)
- 규칙 명세(근거 주소, 매뉴얼과 다른 점, 리메이크 결정): [`remake/docs/rules/`](remake/docs/rules)
- 원본 포맷·역공학 결과: [`remake/docs/original-format.md`](remake/docs/original-format.md)

> 원본 게임 파일, 매뉴얼, 원본에서 추출한 데이터는 저작권 때문에 이 저장소에 없습니다. 원본을 가진 사람이
> `node tools/extract/extract.ts`로 직접 추출해야 실행됩니다.

## 1. 원작과 동일하게 구현한 것

원작 KOREA.EXE(Turbo Pascal 6.0)에 남아 있던 디버그 심볼로 프로시저 285개·전역변수 172개·레코드 구조를 복원하고,
디스어셈블을 읽어 공식과 조건, 판정 순서, 난수 호출 순서까지 옮겼습니다. 매뉴얼과 코드가 다르면 **코드를 따릅니다**.

### 데이터
- 지도 34×66 헥스: 지형 코드, 강·도로·철도 6방향 연결, 도시·항구·비행장·보급 거점, 1995년 지형 변형
- 시나리오 8종: 유닛(1950년대 250개, 1995년 202개), 부대 편성, 장비 15종, 항공대, 보충 풀, 뉴스, 점령, 정찰, 날씨, 비축, UTILITY_SPACE
- 검증: 매뉴얼 부록 F 예시 전투력(북한군 50/15연대 생존 234·살상 418), 시나리오 날짜, 도로·철도 연결 수가 원작 데이터와 일치

### 이동 (MOVE_COST, MOVE_UNIT, NATIONAL_MOVEMENT_RATE)
- 국가별 이동력(유엔 24, 국군·북한 18, 중공 12, 1995년 24), 지형·강·도로·철도 비용표, 혼잡·스택 한도·적 점령지·이탈 비용
- 폭풍·결빙·피란민(유엔군만 도로 불가) 효과, 중공군 험지 감면, "아직 안 움직인 부대는 한 칸은 들어갈 수 있다"(매뉴얼에 없는 규칙)
- 철도 이동(턴당 5회, 차단 손실은 선두 유닛만), 버그아웃, 2차 명령 단계의 이동 중 버그아웃, 미 해병 하구 상륙 예외
- 턴 시작 이동력 공식(준비도·보급망 연동): korea2·3·4의 모든 부대 MOVE 값과 일치
- 되돌리기 제한: 적 점령지 진입, 정찰 안 된 적 점령지 인접(정보 제한일 때)

### 지상전 (GRCMBT, GET_STRENGTH)
- 전투력 5개 모드(기본·공격·방어·정원·돌파), 소프트/하드 지형 배수, 참호, 강 공격 반감, 경험·역량 보정
- 돌파(OVERRUN, 50%), 공격 명령(MOVE에 방향 코드 저장, 6점), 공격 취소(5점 반환)
- 군별 전투 해결, 중포병·함포 지원, 손실률, 장비 손실, 제거·회수 풀, 후퇴(방향 우선순위)·막힘·버그아웃, 전진

### 턴 진행 (KOREA 주 루프, ENDTURN)
- 1차 명령(두 진영) → 전투(정찰, 공중전, 지상전) → 2차 명령 → 정리 → NEXT_TURN
- 선공(비축 기반 RND 200, 시나리오별 고정 턴), 기습 턴의 유엔 1차 단계 없음
- 정리 단계: 재보급, 비축 수송·수요, 증원 도착, 보충 배분·재편성, 공산 요격 수준, 중공군 개입 판정(역사적 1/3 허세 포함),
  기뢰 부설·제거, 순찰·게릴라·평양/함흥 반환, 정찰, 대도시 점령 뉴스, 종료 판정
- 날씨(월별 표, 예보 85/70/55%, 결빙선), 비행장 복구, 피란민, 포로·매장지 뉴스, 1995 추가 미군
- 승리 수준(TERRITORY_BALANCE): 기준값 181(1950년대)·346(1995)이 원작과 일치

### 보급 (SUPPLY)
- 보급망: 원작의 양방향 열 스위프 2회 그대로. 시나리오 파일의 부대 상태와 korea1 35/36, korea3 64/65, korea4 74/74 일치
- 재보급(유엔 차단 수준, 서울 조건, 비축 소모, 공중 보급), 보급 두절 장비 손실

### 항공 (OPSSUBS, AIRCMBT)
- 날씨·기지 약화, 기지 배치(CHOOSE_BASES), 임무 3종, 항공 작전 화면의 예상치
- 1950년대 공산 요격 수준·미그 앨리, 1995 제공권 손실·공군 무력화, 차단(철도 차단·비축 감소), 공습(목표 정찰, 장비·준비도 피해, 대공 사격)
- 컴퓨터 진영(또는 Program Control)의 자동 임무·자동 목표

### 해상·공수 (AMPHIBIOUS, UNIT_COCKED, MOVE_UNIT 해상 분기, GRCMBT)
- 해상 수송 점수(항구 2, 해안 3, 바다 0, 턴당 4), 기뢰 항구 금지, 해안 승선 손실(선두 유닛만), 항구 상륙 1점 반환
- 상륙 공격(턴당 2개), 실패 시 버그아웃 후 일본 철수, 성공 시 전진, 바다에서 낸 명령은 취소 불가
- 187공수 낙하(지형·흐림·미그 앨리 손실, 아군 비행장 0%), 1995 단독 미 해병

### 정보(안개) (SHOW_HEX, UNIT_INFORMATION, FORCE_SPOTTING, DO_INTEL, CHEK_HEX)
- 정찰 단계 0/1/2: 0은 숨김, 1은 부대 종류, 2는 이름과 "완편/정원 미달"
- 정찰 갱신: 단계 시작, 정리 단계, 이동 중 주변 적 발견, 공산군 12점 초과 이동, 전투·후퇴·전진, 공습, 상륙, 공수
- 전력 보고 거짓 표시(STATUS 0x10): 1/3 확률로 미달 부대가 완편으로 보임, 전투를 치르면 정확

### 새 게임 옵션 (SCENARIO_DISPLAY, S_DATA, LOAD_NEW_GAME)
- 원작 시작 메뉴의 6개 항목과 값: 시나리오 4종, 중공군 개입(Historical/Fixed), 공산군 역량(Pushover~Hideous!, Random),
  플레이 모드(Two player, UN Solitaire, Red Solitaire), Air Campaign(Player/Program Control), Intelligence(Limited/Complete)
- Random 역량은 시작할 때 `RND(1,5)`, UN Solitaire(컴퓨터가 공산군)면 편성 배치판(koreaNs.dat)을 읽음
- 표시 규칙: 차가운 강철의 개입은 "이미 개입함", 1995는 "해당 없음", 1950년대 Red Solitaire의 항공은 "프로그램"
- 옵션이 영향을 주는 규칙(역량에 따른 전투력·재보급·비축, 컴퓨터 진영 보정, 0턴 사건 등)은 각 규칙에 이미 들어 있음

### 원작 그대로 둔 특이 동작·버그
고치면 게임 결과가 달라지는 것들은 원작대로 두고 문서에 표시했습니다.
- 적 부대 위 공수 낙하는 늘 전멸 (낙하 뒤 MOVE = 24라 돌파 검사가 늘 실패. 매뉴얼은 "아주 약한 적이면 성공")
- 항구→항구 해상 이동은 턴당 3개(매뉴얼 4개)
- 중국 미개입 시 유엔 승리 제한은 24턴에서만 적용(종료는 26턴)
- 바다 헥스에 남은 점령값을 적 인접·순찰 판정이 읽음
- 공습 목표 유무 검사가 진영과 상관없이 "유엔 점령 육지가 있는가"를 봄
- 매뉴얼의 "공습 피해 보고 과장"(LOSS_INFLATOR)은 원작에서도 값을 읽는 코드가 없어 동작하지 않음

## 2. 원작과 다른 것 (리메이크 결정)

### 화면과 조작 (현대화)
| 원작 | 리메이크 |
|---|---|
| DOS 화면, 키보드·메뉴 중심, 한 칸씩 이동 | 마우스 중심: 부대 클릭 → 갈 수 있는 범위와 남는 이동력 표시 → 마우스 오버 경로·비용 미리보기 → 클릭 고정 → 다시 클릭 실행. 오른쪽 클릭·Esc 취소 |
| Move back(한 걸음씩) | Ctrl+Z로 마지막 이동 명령 하나를 통째로 되돌림(되돌릴 수 없는 경우는 원작 조건 그대로) |
| 영어 | 한국어 전용 화면. 부대 이름·장비·뉴스 한글화 |
| 원작 지도 타일·부대 아이콘 | Canvas 2D 지도, NATO식 부대 기호, 확대·축소(휠·버튼), 방향키·드래그 이동 |
| (없음) | 표시 레이어: 점령지·보급망·부대·지명·산·호수·격자·좌표 |
| 원작 지명(로마자) | 현재 한국 지명(옛 이름 병기), 산 43개·호수 5개 이름과 해발, 헥스별 추정 위경도 |
| 공격 결과 예상 없음 | 공격·상륙 공격 미리보기: 공격·방어 합, 예상 손실률, 후퇴 확률, 돌파 가능 여부(정보 제한이면 적 정보는 감춤) |
| 항공 임무는 다시 눌러 순환 | 임무 버튼 3개, 바꿀 때마다 예상치 갱신, 공습은 "컴퓨터가 고르기"·"남은 공습 맡기기" 추가 |
| 미그 앨리는 제트기 그림 | 지도에 경계 점선 |
| 뉴스 최근 8줄 | 모든 뉴스를 한글로 보관 |
| 해상 이동: 바다 헥스 클릭 → 해안 클릭 | 상륙할 해안만 고르면 옆 바다 헥스를 자동으로 거쳐 상륙 |
| 두 사람 교대 안내 | 단계마다 교대 알림 창. 정보 제한이면 그동안 지도에 부대를 그리지 않음 |
| 종료 후 "계속 싸우기"를 매번 물음 | 한 번 계속하면 다시 묻지 않음 |
| 시작 메뉴: 키 1~7로 값을 순환 | 새 게임 대화 상자: 시나리오 카드 4장과 항목별 버튼(값을 바로 고름), 게임 중에도 상단 "새 게임"으로 열기 |
| 편성 배치판은 UN Solitaire에서만 | 고급 설정에서 기본판·편성 배치판을 직접 고를 수 있음 |
| 시작 시 문서 확인(매뉴얼 단어 맞히기) | 없음 |
| "Scenario Info" 보고서로 현재 설정 확인 | 요약 패널에 현재 설정 줄(무작위 역량은 결과까지) |

### 규칙 처리에서 달라진 점
- **이동 명령은 경로 단위**: 목적지를 고르면 최소 비용 경로를 따라 원작 규칙을 한 칸씩 적용합니다. 공격은 바로 옆 적 헥스만 대상
- **정보(안개)**:
  - 이동 범위는 그 진영이 아는 상태(숨은 적 제외)로 계산합니다
  - 이동 중 적이 드러나면 그 자리에서 멈추고, 숨은 적 헥스로 들어가거나 숨은 적이 있는 해안에 상륙하려 하면 그 헥스만 정찰됩니다(원작은 한 칸씩 움직이므로 그때 다시 판단하는 셈)
  - 전력 보고 거짓 여부는 화면을 볼 때 난수를 쓰지 않고 시드로 정합니다(같은 1/3 확률)
  - 아군 부대는 늘 보입니다
  - 명령 단계에는 자기 공격 화살표만 보이고, 요약의 적 유닛 수는 "?"로 나옵니다
- **표시 전투력**: 지도와 패널 숫자는 매뉴얼 식(1/10 표기)이라 전투에 쓰는 원작 GET_STRENGTH와 ±1 차이가 날 수 있습니다
- **난수**: 원작 RND 대신 시드가 있는 난수(브라우저는 시각 기반 시드, 테스트는 고정 시드). 호출 순서는 원작에 맞춤
- **시작 옵션 기본값**: 원작과 같되 플레이 방식만 "두 사람"(원작 기본은 UN Solitaire). AI가 없어 컴퓨터 진영은 움직이지 않기 때문.
  컴퓨터 진영이 있으면 단계 알림 창의 "자리를 바꾸세요" 문구를 띄우지 않음

### 고친 원작 버그
- 같은 헥스를 노린 다른 공격 명령이 목표가 비어도 남던 문제(GRCMBT `2934`) → 함께 정리
- 육지에서 해상 모드로 바로 옆 적 헥스를 누르면 돌파만 굴리고 이동은 실패하던 문제 → 그 입력을 막음
- 세 번째 상륙 공격을 시도하면 "Illegal move!" → 돌파도 불가능하면 미리 막고, 가능하면 경고 후 허용
- 공수 명령을 취소하면 수요·낙하 손실이 생기고 부대 칸을 덮어쓰던 문제 → 목적지를 고른 뒤에만 실행
- 전진할 때 부대가 둘 있는 헥스의 둘째 칸을 덮어쓰던 문제 → 꽉 찬 헥스에는 전진하지 않음

## 저작권

원작의 저작권은 현재 권리자에게 있습니다. 이 저장소에는 원본 파일과 추출 데이터를 넣지 않으며 개인 학습·개인 플레이 용도로만 씁니다.
공개 배포를 하려면 지도, 전투서열, 그래픽, 문구를 공개 사료로 새로 만들어야 합니다.
리메이크 코드와 `remake/src/data/places.ts`(지명·산·호수 데이터)는 이 프로젝트에서 새로 만든 것입니다.
