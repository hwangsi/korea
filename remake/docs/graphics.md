# 그래픽 (리메이크 추가)

2026-10-17 사용자 결정: **전장(지도)은 시안 D "보드게임 디오라마", 상단 막대·오른쪽 정보 화면·대화 상자는 시안 C "현대 전술 화면(다크)"**.
시안 PNG 5장(A 픽셀 아트, B 1950년대 작전 지도, C, D, D+C 혼합)은 그 세션의 산출물로만 있고 저장소에는 없음. 구현의 기준은 D+C 혼합 시안.

원작 그래픽(LBM)은 쓰지 않습니다. 지도·말은 Canvas 2D로 그리고, 이미지 파일은 시나리오 사진 4장(퍼블릭 도메인)뿐입니다.

## 1. 지도 (시안 D, `src/ui/boardArt.ts`, `src/ui/mapView.ts`)

| 요소 | 그리는 법 |
|---|---|
| 지형 칸 | 지형마다 칠한 육각 타일(`paintTile`). 변형 4가지(헥스 좌표 해시로 고름), 확대 단계(반 옥타브)마다 한 번 그려 캐시(`tileScale`·`tile`). 이웃과 2.5% 겹쳐 이음매가 보이지 않음 |
| 개활지·일본 | 따뜻한 모래·풀빛 바탕, 옅은 밭 얼룩, 점무늬, 나무 한두 그루 |
| 험지 | 왼쪽 위에서 빛을 받는 낮은 언덕 둔덕 + 둥근 나무 무리(그림자·하이라이트) |
| 산악 | 밝은 면·그늘진 면이 있는 봉우리 3개(가장 큰 봉우리 눈), 땅 그림자, 기슭 나무 |
| 도시 | 길 두 줄과 지붕 블록(그림자) |
| 바다 | 한 가지 짙은 파랑(캔버스 바탕과 같음) + 드문 물결. 하구는 모래톱, 저수지는 밝은 파랑 |
| 해안 | `drawCoasts`: 바다 쪽은 얕은 물 띠 두 겹과 흰 파도(점선), 육지 쪽은 모래띠. 각 헥스 안으로 잘라 그림 |
| 격자 | 보드에 인쇄된 옅은 격자(육지 갈색, 바다 흰색). "격자" 레이어를 켜면 진해짐 |
| 강·도로·철도 | 강은 짙은 테두리 + 파랑 + 하이라이트, 도로는 갈색 테두리 + 모래색, 철도는 검정·흰 점선 |
| 점령지 | 아주 옅은 파랑/빨강 덧칠(지형이 보이게) |
| 전선 | 빛나는 빨간 선(그림자 흐림 + 빨강 + 밝은 심) |
| 부대 말 | 두꺼운 판: 판 위의 그림자, 진한 옆면, 위가 밝은 그라데이션 앞면, 안쪽 밝은 테. 국적 색은 `NATION_COLOR`(북한 #c8302c, 국군 #2a78d6 등) |

성능: 화면에 보이는 헥스만 타일을 `drawImage`. 확대를 바꾸면 타일 40여 장을 다시 그림(반 옥타브 단위라 휠 확대 중에도 몇 번뿐).

## 5. 시나리오 브리핑 (`panel.ts` `renderBriefing`, 문안 `ko.ts` `SCENARIO_BRIEF_KO`)

새 게임 창이 열려 있는 동안 오른쪽 패널은 뒤에서 도는 게임(처음 열 때의 기본 게임 포함)이 아니라 **고른 시나리오의 브리핑**을 보여 줌
(사용자 요청 2026-10-17: 처음 화면에 이전 게임 전투 결과가 뜨던 것을 대신함). 카드를 바꾸면 바로 바뀜.

- 구성: 사진 + 제목·원제·날짜 + 한 줄 요약 → 상황 → 유엔군/공산군 두 칸 → 눈여겨볼 곳 3개 → 역사에서는(4는 "실제로는") → 자료 링크·사진 출처
- 문안: 웹 검색으로 사실(병력·날짜·지명)을 확인하고 생성형 AI로 정리. 자료는 시나리오마다 3개
  (위키백과, 미 해군역사유산사령부, 미 육군 군사연구소, 유엔군사령부, 군비통제협회, 미 국무부 페리 증언 등)
- 시나리오 4는 "가상 시나리오" 꼬리표. 배경(1993 NPT 탈퇴 선언, 1994 연료봉 인출, F-117·순항미사일 타격 계획)은 사실,
  공습 실행과 1995년 6월 25일 남침은 가정(게임 첫 뉴스 "북한 특수부대, 한국군 보급 기지 습격", "북한군, 남침 개시"와 맞춤)

## 7. 제목 화면·공습 연출·그림 말 (2026-10-17)

- **제목 화면**(`index.html` `#title-screen`, `main.ts` `showTitle`): 원작처럼 첫 화면은 제목 그림 + "시작 / 저장한 게임 불러오기"
  (원작: "Which do you wish to play? 1 A saved game 2 A new game"). 그림은 생성형 AI 삽화(`data/titleArt.ts`, 1280px JPEG,
  1990년대 전쟁 게임 상자 그림 풍, 글자 없음). Enter·Space·Esc·클릭으로 새 게임 창. 처음 화면의 새 게임 창은 닫을 수 없음(`bootGame`)
- **공습 연출**(`mapView.flashStrikes`): 원작처럼 목표 헥스에 폭발 1~3개가 차례로 커졌다 사라짐(못 찾으면 회색 고리). 컴퓨터가 고른
  공습은 하나씩 시차를 두고. 길이는 진행 속도(GAMEDELAY). 끝난 뒤에는 헥스 위쪽 모서리의 작은 폭발 표시가 그 턴 내내 남음
- **부대 종류별 말 그림**(♪ 설정 "말: NATO 기호 / 그림", `PlaySettings.counters`, 기본 NATO): 보병(소총을 든 병사), 기갑(전차),
  야포(바퀴 달린 포, 중포는 긴 포신), 공수(낙하산) 실루엣(`mapView.pictureSymbol`)
- 1995의 네 자리 전투력은 말 폭에 맞게 글자를 줄임
