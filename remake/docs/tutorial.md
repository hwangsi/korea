# 튜토리얼 (리메이크 추가)

원작에는 튜토리얼이 없고 매뉴얼만 있었습니다. 리메이크는 **매뉴얼의 핵심을 실제 게임 위에서 짚어 주는 안내 카드**를 넣었습니다
(사용자 요청 2026-10-17: 페이즈, 이동, 공격, 전투력, 승패, 항공 지원, 해상 보급은 꼭 포함).

| 파일 | 내용 |
|---|---|
| `src/ui/tutorial.ts` | 단계 목록(`TUTORIAL_STEPS`), 장(`TUT_CHAPTERS`), "직접 해 보기" 판정(`taskDone`, 순수 로직), 카드 그리기(`renderTutorial`) |
| `src/i18n/ko.ts` | `TUTORIAL_KO`: 카드 문구 전부(`steps[id]`: 제목, 문단, 표, 과제, 매뉴얼 절) |
| `src/main.ts` | 시작(`startTutorial`), 단계 이동(`tutGo`), 지도 표시 찾기(`tutMarks`), 게임 상태 읽기(`tutProbe`), 강조 테두리(`refreshTutorial`) |
| `src/ui/mapView.ts` | `tutorialMarks`(노란 점선 헥스와 이름표), `frameHexes`(표시한 헥스가 카드 옆에 다 보이게 지도 맞춤) |
| `tests/tutorial.test.ts` | 모든 단계에 문구, 장 순서, 매뉴얼 핵심 수치가 문구에 있는지, 과제 판정, 카드 |

## 시작하는 곳

- 제목 화면의 **튜토리얼**, 새 게임 창의 **처음이라면: 튜토리얼**, 위쪽 막대의 **튜토리얼** 버튼.
- 튜토리얼 게임: **크로마이트 작전**(시나리오 2, 1950-09-15), 유엔군으로, 컴퓨터 공산군(원작 AI), 정보 완전, 항공 직접 지휘, 역량 역사적.
  유엔군 1차 명령 단계가 있고(시나리오 1·3·4의 첫 턴은 없음), 항구·인천 상륙(일본의 제10군단)·항공이 모두 나와서 골랐습니다.
  공산군이 먼저 움직인 뒤 유엔군 1차 명령 단계에서 시작하며, 그 알림 창은 자동으로 닫습니다.
- 진행 중인 게임에서 위쪽 버튼을 누르면 새 게임이 된다고 확인을 받습니다. 튜토리얼 게임이면 버튼은 카드를 접고 펼칩니다.
- 다른 게임을 시작하거나 불러오면 튜토리얼은 닫힙니다.

## 카드

지도 왼쪽 위에 뜹니다(알림 창보다 아래 층: 알림 창이 뜨면 카드는 뒤에서 흐려짐). 장 이름(눌러서 이동), 제목, 문단과 표,
"직접 해 보기", 원작 매뉴얼 절, 이전/다음과 진행 막대, 접기(작은 버튼으로)와 닫기.
설명하는 화면 요소에는 노란 테두리(`.tut-focus`, 깜빡임)를 두르고, 지도에서 짚을 곳은 노란 점선 헥스와 이름표로 표시합니다.

## 장과 단계 (25단계)

| 장 | 단계 | 강조·표시 | 직접 해 보기 | 매뉴얼 |
|---|---|---|---|---|
| 1. 시작 | 환영, 화면 읽기, 부대 말 읽기 | 위쪽 막대·패널, 부대 하나 | 부대 선택 | 1.3, 1.4, 부록 A |
| 2. 단계 | 한 턴은 네 단계(표), 누가 먼저(비축), 단계 끝내기 | 단계 표시, 단계 종료 | | 2.2, 3.0, 5.0 |
| 3. 이동 | 선택과 범위, 이동력(국적·준비도 표), 지형 비용(표), 특수 이동(표) | 부대, 부대 명령 세 칸, 이동 방식 버튼 | 부대 이동 | 3.41~3.413, 6.13, 5.22, 6.143 |
| 4. 공격 | 공격 명령(6점, 1차 단계만), 돌파와 합동 공격, 전투 결과(손실률, 후퇴 2배) | 공격 부대와 목표, 공격 미리보기 | 공격 미리보기(또는 명령) | 3.41203, 4.2~4.252 |
| 5. 전투력 | 말의 숫자(살상력-생존력), 준비도·경험·참호(표), 지형과 지원(표, 강, 함포) | 부대, 전투력 칸 | | 4.21~4.25 |
| 6. 승패 | 승리 수준(도시 100, 헥스 1, 200점마다 1), 끝나는 때(즉시, 1951-01-08, 1951-05-22, 38선) | 승리 수준 칩, 큰 도시 | | 6.9, 8.0, 9.0 |
| 7. 항공 지원 | 항공 작전 화면과 임무 셋(표), 날씨·기지(표)·요격 수준·미그 회랑, 공습과 차단의 효과 | ✈ 항공, 항공 작전 패널(자동으로 엶) | 항공 화면 열기 | 3.21, 4.11~4.13 |
| 8. 해상 보급 | 보급망과 항구(유엔 보급원 = 기뢰 없는 항구와 일본), 재보급·비축·공중 보급·기뢰, 해상 이동과 상륙(표) | 지도 표시 버튼, 유엔 항구, 인천과 제10군단 | 보급망 켜기 | 6.1~6.14, 6.7, 3.41207, 4.253 |
| 9. 마무리 | 매뉴얼 9.0의 조언 | 단계 종료 | 단계 넘기기 | 9.0 |

- 문구의 수치는 원작 매뉴얼을 따르되 리메이크가 원본 코드대로 구현한 규칙(`docs/rules/*.md`)과 어긋나지 않게 맞췄습니다.
  예: 이동력은 "준비도 75 이상이고 보급망 안이면 전부, 아니면 절반"(movement.md 1장), 공격 뒤 전진은 매뉴얼에 없어서
  "물러난 빈 헥스는 2차 명령 단계에 차지"로 적음, 중국 미개입 종료의 승리 제한은 "도시나 보급 거점을 쥐고 있으면 무승부"로 줄여 적음.
- 지도 표시는 그 순간의 게임에서 찾습니다: 부대 = 적과 맞닿지 않고 이동력 6 이상 남은, 부산 교두보 가운데에 가까운 보병 부대,
  공격 = 공격 가능한 짝 중 예상 손실 차(방어 − 공격)가 가장 큰 것, 항구 = 유엔이 가진 기뢰 없는 한국 항구(부산부터).

## 확인한 것 (브라우저, 2026-10-17)

제목 화면과 새 게임 창 버튼으로 시작, 25단계 넘기기와 장 이동, 과제 다섯 가지(선택·이동·공격 미리보기·항공 화면·보급망·단계 종료)가
실제 조작으로 "완료"로 바뀜, 표시와 지도 맞춤(대구 옆 부대, 공격 짝, 큰 도시, 부산·울산 항구, 인천과 일본), 전투 단계 알림 창이 카드 위에 뜸, 오류 0건.
