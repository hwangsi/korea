# 보고서 화면 (원본 코드 기준)

원작 명령 단계 메뉴의 보고서들과 전략 개관 지도를 디스어셈블로 확인했습니다. 엔진은 `src/engine/reports.ts`(데이터만),
화면은 `src/ui/reports.ts`(상단 "보고서" → 탭 5개), 검증은 `tests/reports.test.ts`입니다.

## 0. 근거가 된 프로시저

| 메뉴 | 내용 | 위치 |
|---|---|---|
| 12h | 전략 보고 "STRATEGIC REPORT" (GAME_OVER 때도 한 번) | REPORTS.STRATEGIC_REPORT `10fd:2f75` (본문 `2f75`~`3577`, 문자열 `2d5f`~`2f74`) |
| 13h | 날씨 보고 "WEATHER REPORT" | REPORTS.W_REPORT `3699` + EURSUBS1.WEATHER_STRING `1816` |
| 14h | 보급망 표시 "Current Supply Nets" | SUPPLY.DETERMINE_SUPPLY(TRUE) `0e96` + 중첩 `082b` |
| 15h | 비행장·항구 "AIRFIELD & PORT STATUS" | REPORTS.PORTS_AIRFIELDS_REPORT `0356` + 중첩 `00b0` |
| 16h | 시나리오 정보 "SCENARIO REPORT" | REPORTS.SCENARIO_REPORT `0010` → TACSUBS.SCENARIO_DISPLAY(FALSE) + S_DATA |
| 버튼 Ovrvw / O | 전략 개관 "Strategic Overview" | EURSUBS1.DO_OVERVIEW `1db8:4421` + 중첩 `4252`, `42a6` |

공통: **난수를 쓰지 않고 게임 상태를 바꾸지 않습니다**(보급망 표시는 지형 바이트 2를 빌려 쓰고 되돌리며 유닛은 건드리지 않음).
한 화면짜리이고 아무 키나 누르면 지도로 돌아갑니다. REPORTS 안의 FULL_HEX(`2c3c`, 중첩 `0a36`~`2c3b`)는 보고서가 아니라
헥스의 아군 부대 편성 화면입니다(아래 5장, `forces.md`).

## 1. 전략 보고

| 항목 | 값 | 리메이크 |
|---|---|---|
| 유엔군·공산군 도시 헥스 / 기타 헥스 | TERRAIN_HELD: 점령값 1·2인 헥스 수(도시 0x93 따로), 만주·가장자리·물 제외, **부대 보관 칸 포함 전체 셀** | `terrainHeld(g)` |
| 보급 비축 | STOCKPILE[1] 유엔, [0] 공산 | `g.stockpile` |
| 유엔 차단 수준 | INTERDICTION[1] | `g.interdiction[1]` |
| 공산 요격 수준(1950년대) / 공산 차단 수준(1995) | RED_AIR / INTERDICTION[0] | `g.redAir` / `g.interdiction[0]` |
| 아군 보충 풀 | REPLACEMENTS[국적][장비]의 둘째 바이트(풀). **PLAYER 쪽만**: 공산군은 NKPA·CPLA(1995는 NKPA만), 유엔군은 US·USMC·CW·UN·ROK(1995의 CW·UN은 "Not available in this scenario.") | `g.replacements[n][t-1][1]` |
| 중공군 개입 상태 | 공산군 플레이어, 1950년대만: 99 미정, 88 개입 안 함, 그 밖 개입 | `g.ccfIntervention` |
| 최근 소식 | NOTES 8줄(마지막 8개, 오래된 것 먼저) | `g.news.slice(-8)` |
| 맨 아래 | 날짜 + "Game Turn:" 시나리오 시작부터 1턴(시작 턴 0·11·20·0) | |

- 정보 제한·정찰과 무관하게 **양쪽의 헥스 수·비축·항공 수준을 정확히** 보여 줍니다. 숨기는 것은 적의 보충 풀과 중공군 개입 상태뿐.
- 승리 수준과 점령 점수는 원작 보고서에 없습니다. 리메이크는 점령 점수(100 × 도시 + 기타)와 승리 수준을 "리메이크 추가(*)"로 함께 보여 줍니다.
- 장비 열: 원작은 15칸 머리글을 늘 찍지만(1995는 7번이 GShp) 리메이크는 그 시나리오에 있는 장비만 열로 보여 줍니다.

## 2. 비행장·항구

- 비행장 AIRFIELDS[0..8], 항구 PORTS[0..11]을 **배열 순서대로 고정 이름**으로(일본 항구 12~17은 목록에 없음): 헥스, 점령(헥스 점령값),
  비행장은 현재·최고 등급(0~3), 항구는 "Mined"/"Clear".
- 양쪽 시설을 모두, 정보와 무관하게 보여 줍니다.
- 리메이크는 현재 지명(places.ts)과 원작 이름을 함께 씁니다. 데이터의 포항 K-3는 (28,52)(매뉴얼 표는 28,56).

## 3. 날씨 보고

- 예보 4줄: **PLAYER의 예보 행**(WEATHER[1] 공산, [2] 유엔)의 0~3열. 0열("Current Conditions")은 DO_WEATHER가 실제 날씨를 넣어 두므로 진짜.
- 날씨 효과는 **실제 날씨** WEATHER[0][0]으로: 준비도 "전투마다 추가 −5"(더위 또는 폭풍), 이동 "+1 road/rough hex"(폭풍, 1995에도
  그렇게 찍히지만 실제 규칙은 1950년대만), 항공 정상/약화(흐림)/크게 약화(폭풍), 결빙선 행 번호 또는 해빙.

## 4. 시나리오 정보, 보급망, 전략 개관

- **시나리오 정보**: 시작 메뉴를 읽기 전용으로(options.md 1). 무작위 역량은 굴린 결과. 리메이크는 표로, 컴퓨터 AI 줄 추가.
- **보급망 표시(14h)**: 지금(이번 단계의 이동 뒤) 보급망을 다시 계산해 미니맵으로: 칠한 색 = 보급망(파랑 유엔, 빨강 공산, 검정 없음),
  점 = 점령. 점령했지만 보급망 밖이면 점만 보임("Dotted = Unsupplied"). 양쪽 모두, 정보와 무관. 리메이크는 전략 개관의 "보급망" 모드
  (지도의 "보급망" 레이어도 같은 계산).
- **전략 개관**: 34 × 66 미니맵, 짝수 열이 반 칸 아래. 칸 색 = 그 헥스 첫째 부대의 진영(빨강 공산, 흰색 유엔, 부대 표시가 켜져 있을 때),
  아니면 지형(개활·강·험지·산·도시·바다·호수·가장자리). 점령 점(점령지 표시가 켜져 있을 때), 도로·철도 점.
  적 부대는 지도와 같은 정찰 규칙(정찰 0인 적 점령 헥스의 적은 안 보임). 헥스를 누르면 지도가 그곳을 가운데로.
- **38선**: 데이터 표가 없고 DO_OVERVIEW가 1950년대에만 **36행과 37행 사이 직선**으로 그림(HANDOFF 8장의 "38선 표시 데이터" 해결).

## 5. FULL_HEX (부대 편성 화면, `forces.md`)

헥스의 아군 부대 두 개를 나란히 보여 주는 편성 화면: 지형 보정, 부대별 살상·생존(모드 0, div 10), 평균 준비도, 남은 이동력(공격 계획이면 +5와 "Atk"),
유닛 보기, 유닛 옮기기(Xfer), 부대 이름 바꾸기, +Hex/−Hex. 모드 3을 쓰지 않음. 규칙 전체와 리메이크 결정은 `docs/rules/forces.md`,
엔진은 `src/engine/forces.ts`, 화면은 `src/ui/organize.ts`(헥스 패널의 "편성" 버튼).

## 6. 리메이크 결정

- 메뉴 대신 상단 "보고서" 버튼 → 탭 5개(전략 보고, 항구·비행장, 날씨, 시나리오 정보, 전략 개관). 모달이라 열려 있는 동안 지도 조작이 멈춤.
- 보는 쪽은 화면의 주인(`viewerSide`): 컴퓨터 상대면 사람 진영, 두 사람이면 지금 명령 단계의 진영.
- 전략 개관은 원작의 키패드 사각형 대신 클릭으로 바로 이동.
