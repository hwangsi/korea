# 해상·공수 이동 규칙 (원본 코드 기준)

원본 KOREA.EXE 디스어셈블과 매뉴얼 3.41205~3.41210, 4.253, 5.1, 6.143을 대조해 정리했습니다.
엔진은 `src/engine/naval.ts`(명령), `src/engine/movement.ts`(MOVE_COST의 해상·공수 분기), `src/engine/combat.ts`(전투 단계의 상륙 공격),
테스트는 `tests/naval.test.ts`입니다. 주소는 `모듈 오프셋`이며 `node tools/disasm/dis.cjs --at MOVEUNIT <시작> <끝>`으로 다시 볼 수 있습니다.

## 1. 모드와 SYMBOL

MOVE_UNIT(param)의 `param div 2`가 모드입니다: 0 일반, 1 철도, 2 해상, 3 공수(`param mod 2`는 헥스의 첫째/둘째 부대).
특수 이동 중에는 선두 유닛의 SYMBOL을 잠시 바꿔 국가 이동력을 98("Unlimited")로 만듭니다: 해상 81, 공수 82, 철도 83.
바다 헥스에 있는 부대는 헥스 화면에서 일반·철도 버튼이 막히고(58h), 부대를 고르면 바로 해상 모드(4)가 됩니다.

## 2. 해상 이동

### 2.1 자격 (AMPHIBIOUS)

모두 만족해야 합니다.

1. 해안(깊은 바다 0xA5~0xDA에 인접, OCEAN_ADJACENT) 또는 깊은 바다 헥스에 있음. 하구·저수지만 닿은 헥스는 해안이 아님
2. 이번 턴 미이동 (STATUS 0x04 없음)
3. 폭풍이 아님. 단 이미 바다에 있으면 폭풍이어도 가능
4. 1차 명령 단계 (PHASE 1)
5. 유엔 부대 (유닛 번호 ≥ FIRSTUNUNIT)
6. 해상 수송 여유: `4 − SEALIFT_DEMAND ≥ 출발 점수`. 출발 점수(`19a0`): 깊은 바다 0, 기뢰 없는 항구 2, 그 외 3
7. 1995: SEALIFT_DEMAND = 0 (턴당 1회), 그리고 선두가 단독(ATTACHED = 0)이고 국적이 미 해병(SYMBOL div 10 = 1)

공격 계획이 있는 부대는 STATUS 0x04가 있으므로 해상 이동을 할 수 없습니다.

### 2.2 시작 (MOVE_UNIT `4804`)

- 바다가 아닌 곳에서 시작하면 "Do you wish to move this force by sea?" → 예이면 SYMBOL = 81
  - 항구(`01f0`, 기뢰 없는 항구)면 SEALIFT_DEMAND +2
  - 아니면 +3, 그리고 **선두 유닛만** BUGOUT (장비 칸마다 보유 −1개에 대해 `RND(1,15) > 생존력`이면 1개 손실, 준비도 최대 50)
- 바다에서 시작하면 묻지 않고 해상 모드, 수요 없음

### 2.3 헥스 비용 (MOVE_COST, 해상)

- 거리: 목표가 깊은 바다면 **거리 무관**. 그 외는 인접 헥스만
- 깊은 바다 비용 0. 하구·저수지는 불가 (미 해병 하구 예외는 SYMBOL이 81이라 적용 안 됨)
- 수정치: 혼잡 +1·적 점령지 +1·이탈 +4 **없음**. 스택 한도(아군 부대 2개)는 바다 헥스에도 적용
- 적 부대가 있는 육지: 일반 이동과 같은 적 헥스 분기. 바다에서 MOVE는 0, 한도는 98이므로 늘 OVERRUN 판정(50%)을 함
  - 돌파 성공 → 비용 = 한도(상륙), 실패 → 100(공격 계획)
- 해상 분기(`1588`~`1711`):
  - 기뢰 항구 → 불가 ("Can't land in mined hex"), 적이 있어도 마찬가지
  - 육지 비용이 0 < c < 13이면 "Come ashore in hex: x,y?" → 예: 비용 = 한도(98, 상륙), 아니오: 불가
  - 출발과 목표가 모두 깊은 바다가 아니면 불가 (육지에서 육지로는 해상 이동이 아님: 먼저 바다로 나가야 함)

### 2.4 한 걸음과 끝

- 바다 헥스로 갈 때마다 MOVE = 0 (`3848`), 점령·정찰은 바꾸지 않음 (`3e1f`), 준비도 손실 없음
- 상륙(비용 ≥ 한도, `3961`): SYMBOL 복원, MOVE = 국가 이동력 → 이동 종료. 그 헥스는 일반 이동처럼 점령(비행장 등급 포함)되고, 적 인접이면 정찰 1
- **바다에서 "Finished"로 멈출 수 없음**(`2536`): 해상 이동은 상륙하거나 상륙 공격을 명령해야 끝남. 'S' 버튼은 경유점 세 곳으로 바로 옮겨 주는 편의 기능
- 끝(`44fd`): SYMBOL 복원, 공격 계획이 없으면 MOVE = 국가 이동력, **항구에 있으면 SEALIFT_DEMAND −1**, 부대 유닛 위치·MOVE 동기화
- 되돌리기 불가 (바다 헥스는 아군 점령이 아니라 되돌리기 기록이 막힘)

## 3. 상륙 공격 (바다에서 적 부대가 있는 해안 헥스로)

1. MOVE_COST의 적 헥스 분기가 OVERRUN(부대, 바다 헥스, 목표, 2, ...)을 굴림: `aL div dS > 95`, `dL div aS < 2`, `RND(1,2) = 1`, 남은 이동력 ≥ 6(바다에서는 늘 참)
   - 성공: 선두 유닛 UNIT_ATTRITION(`dL div aS`), 방어 유닛 전원 BURY, 그 헥스로 상륙(2.4), 항구면 수요 −1
2. 실패 → 비용 100 → `23f2`:
   - CLEAR_PLOTS, SYMBOL 복원
   - 모든 유닛 남은 이동력 6 이상(`2289`, 바다에서는 늘 참) **그리고** UTILITY_SPACE[9] ≤ 1이어야 함. 아니면 "Illegal move!"이고 이동이 끝나 부대는 바다에 남음(MOVE = 국가 이동력)
   - `22e3`: 목표 헥스 정찰 0이면 1, 각 유닛 `MOVE = 국가 이동력 + 방향코드×100 + 5`, STATUS |= 0x04, &= ~0x40, **UTILITY_SPACE[9] + 1**
3. 바다에서 내린 공격 계획은 취소할 수 없음 (MOVE_UNIT `49b7`이 바다 위에서는 "Cancel assault order?"를 건너뛰고, AMPHIBIOUS도 이동한 부대를 거부)
4. UTILITY_SPACE[9]는 NEXT_TURN에서 0. → **턴당 상륙 공격 명령은 2개**(매뉴얼 3.41207과 같음)

### 3.1 전투 단계 (GRCMBT, 매뉴얼 4.253)

- 공격 실행 분류는 지상 공격과 같음: 목표가 비었거나 아군 쪽이면 바로 진입(바다에서 상륙), 적 부대가 있으면 전투
- 전투(`1f9d`): 후퇴 판정 → 공격 부대 손실·제거 → **바다 위 공격 부대이고 방어가 후퇴하지 않았으면 `1e11`**:
  선두를 바다 헥스에서 빼고, 일본 열(33, 59~64)에서 부대 자리가 남은 가장 위쪽 헥스를 찾아, 부대 모든 유닛 BUGOUT 후 그곳으로 옮김. 자리가 없으면 모든 유닛 ELIMINATE
- 방어가 후퇴했으면(`2e7f`): 방어 부대 후퇴 뒤 그 목표의 첫 공격 부대가 바다 위이고 헥스가 비었으면 `2458` 전진:
  같은 목표의 공격 부대마다 `RND(1,100)`, 선두 준비도가 그보다 크고 헥스가 비었거나 **바다 위 부대면 무조건** 진입(점령, 정찰)
- 지상 공격 부대는 방어가 후퇴해도 전진하지 않음 (combat.md 3). 미리 비어 있던 목표(`2f25`)도 `2458`을 쓰므로 바다 위 부대는 무조건 전진
- 후퇴했지만 막혀서 방어가 남으면 공격 부대는 바다에 남음 (다음 턴 바다에서 시작: 매뉴얼의 "드문 경우")

## 4. 턴 정리와 수송 수요

- 정리 단계 GROUND_REINFORCEMENTS: 유엔 수요 = AIRLIFT_DEMAND + SEALIFT_DEMAND (폭풍이면 4로 덮어씀) + 유엔 철도 수, 유엔 비축 = `+ u − 수요`(supply.md 3)
- 그 뒤 SEALIFT_DEMAND = **바다 헥스에 있는 부대 수**(다음 턴 해상 수송 여유에서 미리 빠짐), AIRLIFT_DEMAND = 0
- REST_UP은 바다 위 부대의 턴 시작 MOVE를 0으로 (movement.md 1). 바다 헥스는 보급망이 아니므로 재보급은 실패(유엔 공중 보급 대상)

## 5. 공수 이동 (1950년대, 미 187 공정연대전투단)

### 5.1 자격 (UNIT_COCKED)

SYMBOL 3(미 공수), 시나리오 1~3, 9개 비행장 중 하나의 위치(점령·등급과 무관) 또는 일본(33, 59~64), 미이동(STATUS 0x04 없음),
폭풍 아님, 단독(ATTACHED = 0). **명령 단계 검사가 없어** 2차 명령 단계에서도 가능합니다(매뉴얼 5.1은 불가).

### 5.2 이동

- "Do you wish to move this unit by air?" → 예: SYMBOL = 82, **AIRLIFT_DEMAND +2**
- MOVE_COST: 지도 안이면 거리 무관, 지도 가장자리(0x8F)·만주(0x94)만 불가, 그 외 비용 0 (물·적 부대·꽉 찬 헥스도 지나감)
- 헥스마다 건너뛰기(`3a8f`): 들어간 헥스의 TERRAIN 바이트 1~4를 저장하고 점령을 아군·정찰 1·부대 칸을 자기로 바꿨다가, 다음 헥스로 가면 되돌림.
  공수 중에는 점령 변경 코드(`3e07`)를 건너뛰므로 **비행장 등급은 바뀌지 않음**
- 멈춤(`2536`): 물(0xA5 이상) 불가, 유엔 점령이고 부대 2개면 불가, 공산 점령이면 "Stopping here may destroy the unit!" 확인

### 5.3 낙하 (`422b` → `2645`)

- MOVE = 24 (더 움직일 수 없음), SYMBOL 3 복원
- 손실률 = 지형(개활지·도시·기타 5, 험지 0x58~0x91 10, 산악 0x92 25) + 하늘이 맑음이 아니면 5 + 미그 앨리(x ≤ 14, y ≤ 26)면 공산 요격 수준(RED_AIR).
  **원래 유엔 점령인 비행장 헥스면 0**. UNIT_ATTRITION(손실률): 장비 칸마다 둘째 개부터 `RND(1,100) < 손실률`이면 1개 손실, 준비도 −손실률(최소 20)
- 그 헥스에 원래 공산 점령이고 적 부대가 있었으면(`274d`): 적 부대를 되돌려 놓고 OVERRUN(공수, 그 헥스, 그 헥스, 1, ...)
  → **남은 이동력 6 검사에서 MOVE가 이미 24라 늘 실패** → 저장한 헥스를 되돌리고 "airborne unit has been destroyed!" + BURY
- 성공(적 부대 없음): 그 헥스는 유엔 점령·정찰 1로 남고 부대가 들어감 (첫째 칸이 비었으면 첫째, 아니면 둘째)
- 되돌리기 불가

| 전진 시 꽉 찬 헥스 | 부대 2개면 더 전진하지 않음 | 원작 `2458`은 둘째 칸을 덮어씀 |

## 7. 매뉴얼과 코드가 다른 점

- 해상 수송: 매뉴얼은 "항구→항구 1점씩 4개 부대"지만, 시작 검사가 `4 − 수요 ≥ 2`라서 실제로는 **3개**(3번째 뒤 수요 3)
- 해안 승선 손실: 매뉴얼은 부대 전체지만 코드는 **선두 유닛만** BUGOUT
- 상륙 실패(일본 철수)의 버그아웃은 부대 **모든 유닛** (매뉴얼과 같음)
- 적 부대 위 공수 낙하: 매뉴얼은 "아주 약한 적이면 돌파로 점령"이지만 코드는 낙하 뒤 MOVE = 24라서 **늘 전멸**
- 공수 이동: 매뉴얼 5.1은 2차 명령 단계 불가지만 UNIT_COCKED에 단계 검사가 없음
- 공수 손실 0: 매뉴얼은 "friendly airbase"이고 코드는 "비행장 위치이면서 원래 유엔 점령"(등급 0이어도 0%)
- 비행장 위치면 점령과 관계없이 이륙 가능 (유엔 부대가 서 있으니 사실상 아군)
- 바다 위 부대의 폭풍 예외, 1995 단독 미 해병, 기뢰 항구 금지는 매뉴얼과 같음
