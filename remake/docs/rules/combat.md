# 지상전 규칙 (원본 코드 기준)

원본 KOREA.EXE 디스어셈블과 매뉴얼 3.41203, 4.2~4.253, 5.2, 부록 F를 대조해 정리했습니다.
엔진은 `src/engine/combat.ts`, 테스트는 `tests/combat.test.ts`입니다. 주소는 `모듈 오프셋`.

| 내용 | 위치 |
|---|---|
| 전투력 | EURSUBS1.GET_STRENGTH `1db8:1c16`, GET_FORCE_STRENGTH `1db8:1aee` |
| 돌파 | MOVEUNIT.OVERRUN `1915:0733`(본문은 `0b57` 앞까지), MOVE_COST 적 헥스 분기 `14c4`~`1588` |
| 공격 명령 | MOVE_UNIT 중첩 `40b7` → `23f2`(명령), `2075`(방향 코드), CLEAR_PLOTS `17da` |
| 전투 해결 | GRCMBT.DO_GROUND_COMBAT `3357`, 군별 실행 `2f9c`, 해결 `2934`, 전투 `1f9d`, 손실률 `0715`, 손실 `0846`, 후퇴 `15d7`/`12d8`/`1129`, 지원 `0b39`, 함포 `009c`, 제거 `0656`/`0400`, EURSUBS1.BURY `1db8:5481` |
| 실행 시점 | KOREA 주 루프: PHASE_PULSE(1) → PHASE 2(정찰, 공중전, DO_GROUND_COMBAT) → PHASE_PULSE(3) → REST_UP → NEXT_TURN |

## 1. 전투력 GET_STRENGTH(unit, x, y, mode)

모드: 0 기본(제거 판정), 1 공격, 2 방어, 3 정원 기준(보고서), 4 돌파 공격.

1. 장비 칸마다 `l = n·살상·준비도 div 100`, `s = n·생존·준비도 div 100` (칸마다 버림, 모드 3은 정원·준비도 100).
2. 모드 2·4는 그 헥스 지형으로 생존력 배수: 소프트(소총소대·화기소대, 장비 12·13)와 하드(나머지)가 다름.

   | 지형 | 소프트 | 하드 |
   |---|---|---|
   | 개활지 등 | ×1 | ×1 |
   | 도시 0x93 | ×3 | ×2 |
   | 험지(0x58~0x8E) | ×2 | ×1 |
   | 산악 0x92 | ×2 | ×0.5 |
3. 모드 4(돌파), 1950년대, 헥스 코드 ≤0x57 또는 ≥0x95: 중형 전차(장비 2)는 살상 ×6, 생존 ×4 (매뉴얼은 ×4/×4).
4. 1995 북한 특수부대(SYMBOL 53): TURN < 4이면 살상 ×(4−TURN) (방어 때도).
5. 경험: `x += (x div 4)·(경험−1)` (숙련 ×1.25, 정예 ×1.5).
6. 모드 1(공격): 강이 있는 헥스(도로 강 포함, 0x01~0x0F, 0x47~0x57, 0x59~0x6F, 0x8C~0x8E, 0x9D~0x9E)이고 결빙이 아니면 살상 ÷2. 포병과 단독 특수부대 제외.
7. 모드 2(방어), STATUS 0x40(참호, 준비도 75+이고 이번 턴 미이동): 살상 ×5/3, 생존 ×5/2 (매뉴얼 1.65/2.5).
8. 공산군: `x += (x div 10)·(역량−3)` (역량 1~5 → ×0.8~×1.2).

부대 전투력은 유닛 합. 전투 합산 단위는 부대마다 `살상 div 5`, `생존 div 50`.

## 2. 적 헥스로 들어가기: 돌파 또는 공격 명령

MOVE_COST의 적 헥스 분기: 지형 비용 c를 구한 뒤
- 쓴 이동력 + c > 국가 이동력 → 공격 명령으로 (돌파 판정 없음)
- 하구에서 출발 → 불가
- 그 외 OVERRUN(확률 1/2):
  - 방어: 헥스의 각 부대 `dL += L div 5`, `dS += S div 50` (모드 2, 그 헥스). 포병 부대가 나오면 누적합 전체 ÷4(원작 그대로). dS 최소 1.
  - 공격: 모드 4, **자기 헥스** 기준. `aL = L div 5`, `aS = max(1, S div 50)`.
  - 조건: `aL div dS > 95` 그리고 `dL div aS < 2` 그리고 `RND(1,2) = 1` 그리고 선두 유닛 남은 이동력 ≥ 6
  - 성공: 선두 유닛 UNIT_ATTRITION(dL div aS = 0 또는 1), 방어 유닛 전원 BURY, 공격 부대는 일반 이동처럼 진입
    (지형 비용, 여유가 있으면 +1, 준비도 감소, 점령)
- 돌파 실패 또는 불가 → 공격 명령(PLOT): 모든 유닛 남은 이동력 6 이상 필요.
  `MOVE += 방향코드×100 + 6` (방향코드 = 3·dy + dx + 5, 직사각 좌표 차), STATUS |= 0x04, &= ~0x40. 부대당 1개.
- 공격 명령 취소(CLEAR_PLOTS): 100의 자리를 지우고 5를 돌려줌 → 1점은 소모.
- 2차 명령 단계(PHASE 3) 사람 쪽은 공격 명령 대신 이동력 소진(MOVE = 국가 이동력)으로 끝남.

## 3. 전투 해결 DO_GROUND_COMBAT

- 순서: `RND(1,10) ≤ 6`이면 유엔 쪽 먼저(국군 → 기타 유엔 → 북한군 → 중공군), 아니면 북한군 → 중공군 → 국군 → 기타 유엔.
  군(CORPS)마다 따로 실행·해결 (지휘 통제: 다른 군끼리는 합치지 않음, 같은 군이 같은 헥스를 노리면 합침).
- 군별 실행: 유닛 번호 순으로 공격 명령이 있는 부대 선두마다 목표를 판정
  - 목표가 비었거나, 적 점령이 아니고 자리가 있으면 → 즉시 진입(점령, 정찰 1, 주변 적 헥스 정찰 2)
  - 적 점령이고 적 부대가 있으면 → 전투 대기열
  - 그 외 → 명령 취소
  - 진입·전투 모두 부대 전 유닛 준비도 −3 (매뉴얼은 −5)
  - 명령 정리 015F: `MOVE := MOVE mod 100`, 국가 이동력으로 상한. **5점 환불 없음** → 공격에는 총 6점 소모
- 목표마다 전투: 공격 합(각 부대 모드 1, 자기 헥스) + 지원, 방어 합(헥스의 부대들, 모드 2) + 지원
  - 지원(0B39): 같은 진영(국적 무관) 중포병(SYMBOL mod 10 = 4)이 목표에서 1~2칸이면 `L div 5`와 `S div 50`(포병 자기 헥스 모드 2)을 더함. 호출마다 준비도 −2, 진영마다 2번 호출 → −4. 지원 표시 때 경험 50% 상승 기회.
  - 함포(009C, 1950년대 유엔 쪽, 목표가 깊은 바다에 인접): 턴 ≤4: 0, ≤8: 50, ≤20: 100, 이후 125, 폭풍 ÷2. 살상에 그대로, 생존에 ÷10.
- 손실률(0715): 각 쪽 생존 최소 1, 상대 살상 div 2 후 `3·L div S`, 1995는 0턴 ×2·이후 ×7/4, 1~100으로 제한.
  결과적으로 `15 × 상대 살상 합 / 자기 생존 합 %` = 부록 F 공식.
- 후퇴 판정: `(2·방어 손실률) div (도시면 2) + 보정 + (방어 선두에 신병 있으면 20) ≥ RND(1,100)`.
  보정은 컴퓨터 쪽 방어 −5, 사람 쪽 +5 (두 사람 대전은 0).
- 손실 적용(0846, 부대 전 유닛): 장비 하나하나 `RND(1,100) ≤ 손실률 − AI감면`이면 손실(마지막 1개도),
  경험 +1 확률 50%(AI 쪽 60%, 후퇴하는 방어는 없음), 준비도 −(손실률 − 감면), 더위·폭풍 −5, 그 뒤 50~100으로 제한.
  AI 감면: 컴퓨터가 공산군이면 손실률 div (13−역량), 컴퓨터가 유엔이면 손실률 div 10.
- UTILITY_SPACE[7]: BURY되는 유엔 유닛과 후퇴 판정을 받는 유엔 부대(GRCMBT `1641`)마다 +1 → 5 이상이면 다음 턴 피란민 (turn.md 5)
- 제거(0656): 원래 생존력 < 10(표시 1 미만)인 유닛은 BURY → 보관 칸(1,0), 준비도 50, 신병, STATUS 8, 남은 장비 절반을
  REPLACEMENTS[국적][장비][1](제거 부대 회수 풀, 최대 255)로. 선두가 제거되면 다음 유닛이 부대를 이어받음.
- 후퇴(15D7): 둘째 부대부터. 이웃 6칸 점수 → 무작위 선택
  - 불가: 지도 밖, 부대 2개, 결빙 아닌 다리 없는 강(0x01~0x0A, 0x59~0x66), 물, 만주
  - 유엔은 아군 점령지만, 공산군은 비어 있으면 적 점령지도 가능(그 헥스를 점령)
  - 선호 방향(유엔 남쪽 y 증가, 공산군 북쪽)이 하나라도 있으면 그 칸들만
  - 후퇴하면 MOVE = 국가 이동력(2차 명령 단계 이동 불가), STATUS |= 0x02, 참호 해제, 신병 유닛은 손실률 확률로 버그아웃
  - 갈 곳이 없으면 같은 손실률로 손실 한 번 더 + 제거 판정
- 지상전 뒤 공격 부대는 **자동 전진하지 않음**(해상 상륙만 전진). 2차 명령 단계에서 이동해 들어가야 함.
- 바다 위 공격 부대(상륙 공격, `naval.md` 3.1): 방어가 후퇴하지 않으면 모든 유닛 버그아웃 후 일본(33, 59~64)으로 철수(`1e11`),
  후퇴해 헥스가 비면 무조건 전진(`2e7f` → `2458`). 미리 비어 있던 목표도 바다 위 부대는 무조건 전진

## 4. 리메이크 결정

| 항목 | 결정 |
|---|---|
| 공격 대상 | 이동 모드에서 선택 부대 **바로 옆** 적 헥스만 (원작도 한 칸씩 진입 시도) |
| 미리보기 | 원작 공식 그대로 공격·방어 합, 예상 손실률, 후퇴 확률, 돌파 가능 여부를 표시 (부작용 없는 계산) |
| 전투 해결 | 1차 명령 단계가 끝나면 PHASE 2에서 자동 실행 (turn.md 1), 결과는 패널에 보고 |
| 역량 | 원작은 시작 메뉴에서 고름. 옵션 화면 전까지 3(×1.0) |
| 비운 목표 버그 | 원작 2934는 목표가 비면 전진만 하고 같은 목표의 다른 명령을 남겨 둠 → 함께 정리 |
| 중공군 첫 참전 뉴스, 정찰 표시 비트(0x10/0x20) | 뉴스는 아직 없음, 비트는 원작처럼 설정만 |
