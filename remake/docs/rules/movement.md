# 이동 규칙 (원본 코드 기준)

원본 KOREA.EXE 디스어셈블과 매뉴얼 3.41, 5.1, 5.2, 6.13을 대조해 정리한 이동 규칙입니다.
엔진 구현은 `src/engine/movement.ts`, 검증은 `tests/movement.test.ts`입니다.
주소는 `모듈 세그먼트:오프셋`이며 `node tools/disasm/dis.cjs --at MOVEUNIT <시작> <끝>`으로 다시 볼 수 있습니다.

(예: OVERRUN 길이 안에 MOVE_COST의 중첩 함수 3개, CAN_ENTRAIN 길이 안에 MOVE_UNIT의 중첩 함수 전부).
`dis.cjs --all`은 이제 이런 빈 구간을 `(unnamed before X)`로 함께 출력합니다.

## 1. 이동력의 의미

- `UNIT.MOVE`는 **이번 턴에 이미 쓴 이동력**입니다. 남은 이동력 = 국가 이동력 − (MOVE mod 100).
  화면의 "Movement Allowance"도 `NATIONAL_MOVEMENT_RATE − MASK(MOVE)`로 계산합니다 (`1915:2005`).
- 100의 자리 이상은 **공격 계획**입니다. 인접 적 헥스에 공격을 걸면 `MOVE += 방향코드×100 + 5`
  (방향코드 = 3·dy + dx + 5, 1~9, `1915:2075`) 와 진입 비용 1이 더해집니다. 그래서 S 시나리오에 406, 815 같은 값이 있습니다.
  이동을 시작하면 CLEAR_PLOTS가 공격 계획을 지우고 예약분 5를 돌려줍니다 (공격 비용 1은 남음).
- 부대(Force)는 선두 유닛 기준으로 움직입니다. 비용 계산과 이동력은 선두 유닛의 국가·MOVE를 쓰고,
  한 걸음마다 부대의 모든 유닛 MOVE를 선두와 같게 맞춥니다.

### 국가 이동력 (NATIONAL_MOVEMENT_RATE)

SYMBOL ÷ 10 (국적)으로 정합니다. 1995년 시나리오는 국적과 관계없이 24.

| 국적 | 1950년대 |
|---|---|
| 미군, 미 해병, 영연방, 기타 유엔 (0~3) | 24 |
| 국군, 북한군 (4~5) | 18 |
| 중공군 (6) | 12 |
| (7) | 18 (사용 안 함) |
| 8 = 특수 이동 중 | 98 = "무제한" (해상 81, 공수 82, 철도 83으로 SYMBOL을 잠시 바꿈) |

### 턴 시작 이동력 (SUPPLY `0531`~`0733`)

보급 판정 직후 헥스마다 각 부대에 대해:

1. 평균 준비도 = 부대 유닛 준비도 합 ÷ 유닛 수 (정수 나눗셈). 준비도 75 이상인 유닛은 STATUS에 0x40.
2. 평균 75 이상이고 그 헥스가 보급 상태면 MOVE = 0 (전부 사용 가능)
3. 그 외에는 MOVE = 국가 이동력 ÷ 2 (절반)
4. 평균이 정확히 50이고 보급 상태가 아니면 MOVE = 국가 이동력 (이동 불가)
5. 중공군은 MOVE가 0이 아니면 3으로 (항상 최소 9)
6. 바다 헥스에 있거나 단독 특수부대(1995 북한 SYMBOL 53)면 MOVE = 0

매뉴얼 6.13의 표(0-50 / 51-74 / 75-100)와 결과는 거의 같지만, 실제로는 **보급 여부**가 75 이상 구간을 결정하고,
준비도는 재보급 단계에서 최소 50으로 올라가므로 "0"은 평균 50이면서 보급이 끊긴 경우뿐입니다.
시나리오 시작 때는 파일의 MOVE 값을 그대로 쓰고, 매 턴 정리 단계의 REST_UP(`supply.ts`의 `restUp`)이 보급망과 함께 이 함수(`turnStartMove`)를 부릅니다.
"보급 상태"는 유닛의 재보급 성공이 아니라 **그 헥스가 자기 진영 보급망에 있는지**입니다 (supply.md 1장).

## 2. 이동 시작과 한 걸음의 허용 조건

- **시작** (`317f`): 쓴 이동력 ≥ 국가 이동력이면 이동할 수 없습니다. 단, 이번 턴에 아직 움직이지 않았다면
  **버그아웃**을 명령할 수 있습니다: 모든 유닛이 BUGOUT 손실을 입고 MOVE = 국가 이동력 − 6 (6점 이동).
  - BUGOUT: 장비 칸마다 (보유 수 − 1)개에 대해 `RND(1,15) > 생존력`이면 1개 손실 (항상 1개는 남음), 준비도는 최대 50.
- **한 걸음** (`3806`~`3845`): 비용 c에 대해 `쓴 이동력 + c ≤ 국가 이동력`이면 이동합니다.
  아니더라도 **이번 턴에 아직 움직이지 않았고(STATUS 비트 0x04 없음) c ≤ 국가 이동력**이면 한 칸은 들어갈 수 있고,
  이때 쓴 이동력은 국가 이동력으로 잘립니다. (매뉴얼에 없는 "최소 1칸 이동" 규칙)
- 이동하면 STATUS |= 0x04 (이동함), STATUS &= ~0x40.
- 준비도는 걸음마다 비용만큼 1%씩 감소합니다 (비용 ≤ 국가 이동력일 때만, 철도·해상·공수는 감소 없음).
- 걸음마다 헥스 점령이 바뀝니다 (육지, 공수 제외): 적 점령 헥스에 들어가면 아군 점령이 되고 그 헥스 정찰 단계가 1이 됩니다.
  그 헥스의 비행장은 공산군이 점령하면 등급 0, 유엔군이 점령하면 1이 됩니다.
- 공산군 부대가 쓴 이동력이 12를 넘으면 `RND(1,4) < 하늘 코드`일 때 그 헥스 정찰 단계가 1 오릅니다 (정보 시스템 구현 때 연결).

## 3. 헥스 진입 비용 (MOVE_COST)

인자: 목표 헥스, 출발 헥스, 선두 유닛, 공수·해상·철도 여부. 결과가 "불가"면 국가 이동력 + 1을 돌려줍니다.

### 3.1 기본 확인

- 목표가 지도 밖이면 불가. ON_MAP은 x 0~33, y 0~65이면서 (x < 2 그리고 y < 2)인 왼쪽 위 구석(부대 보관 칸)은 제외.
- 목표는 인접 헥스여야 합니다 (공수는 예외, 해상은 목표가 바다면 예외). 원본 DIST는 even-q 헥스 거리와 같습니다 (전 지도 검증).

### 3.2 지형 비용 (목표 헥스 코드 기준)

| 코드 | 지형 | 비용 |
|---|---|---|
| 0x00 | 개활지 | 2 |
| 0x58 | 험지 | 3 |
| 0x92 | 산악 | 4 |
| 0x93 | 도시 | 2 (철도 이동 중 철도 연결이면 0) |
| 0x8F, 0x94 | 지도 가장자리, 만주 | 불가 |
| 0xA5~0xDA | 바다 | 해상 이동만 0, 그 외 불가 |
| 0xDB~0xFF | 하구, 저수지 | 미 해병 상륙 예외(3.6)만 0, 그 외 불가 |
| 0x01~0x0A | 개활지+강 | 2 + 강 비용 |
| 0x0B~0x0F | 개활지+도로+강 | 도로 연결 2, 아니면 3 |
| 0x10~0x1D | 개활지+도로 | 도로 연결 1, 아니면 2 |
| 0x1E~0x46 | 개활지+도로+철도 | 도로 연결 1, 아니면 2 |
| 0x47~0x57 | 개활지+도로+철도+강 | 도로 연결 2 (0x50만 1), 아니면 3 |
| 0x59~0x66 | 험지+강 | 3 + 강 비용 |
| 0x68~0x6F | 험지+도로+강 | 도로 연결 3 (1995년 2), 아니면 4 |
| 0x71~0x7C | 험지+도로 | 도로 연결 2 (1995년 1), 아니면 3 |
| 0x7F~0x89 | 험지+철도 | 3 |
| 0x8C~0x8E | 험지+철도+강 | 4 |
| 0x95~0x9C | 개활지+철도 | 2 |
| 0x9D~0x9E | 개활지+철도+강 | 3 |

철도 이동 중에는 철도가 있는 코드(0x1E~0x57, 0x7F~0x8E, 0x95~0x9E, 도시)만 철도 연결이면 0, 아니면 불가입니다.
실제 지도에 쓰인 코드는 위 범위로 모두 덮입니다 (0x67, 0x70, 0x7D, 0x7E, 0x8A, 0x8B, 0x9F~0xA4는 지도에 없음).

**강 비용** (`0df6`): 4. 목표 헥스가 결빙이면 0, 아니면 폭풍일 때 6. 부대에 1995 북한 특수부대(SYMBOL 53)가 있으면 0.
강 비용은 강 헥스(도로 없는 0x01~0x0A, 0x59~0x66)에 들어갈 때 **강변을 실제로 건너는지와 관계없이** 붙습니다.
도로가 있는 강 헥스는 위 표처럼 고정값이며 결빙·폭풍의 영향을 받지 않습니다.

**결빙** (FROZEN): y ≤ 결빙선이고, (y ≤ 결빙선 − 5 이거나 깊은 바다 0xA5~0xDA에 인접하지 않음).

**도로 연결** (`0b57`): 목표 헥스의 도로 마스크(ROADS[코드 − 0x0B])에 출발 헥스 쪽 변이 있어야 합니다 (출발 헥스 쪽은 보지 않음).
그리고 1950년대 시나리오의 폭풍 턴이 아니어야 하고, **피란민(REFUGEES) 턴에는 유엔군만** 도로를 쓰지 못합니다.

**철도 연결** (`0cc3`): 목표 헥스의 철도 마스크(RAILS[코드 − 0x1E])에 출발 헥스 쪽 변이 있어야 합니다.
목표가 도시면 반대로 출발 헥스의 철도 마스크에 목표 쪽 변이 있어야 하고, 출발이 도시면 항상 연결로 봅니다.
추가로 목표가 아군 점령(또는 바다)이고, 출발·목표 헥스 모두 적에 인접하지 않아야 합니다.

### 3.3 수정치 (순서대로 적용)

1. 중공군(CORPS 2번째 범위)이면 비용 3 → 2, 4 → 3 (강·도로 조합 결과에도 적용)
2. 철도 이동 중 비용이 0보다 크면 불가
3. 목표에 아군 부대가 1개 이상: +1 (혼잡, 해상 이동 제외)
4. 목표에 아군 부대가 2개: 불가 (스택 한도, 철도 이동 중에는 통과 가능)
5. 목표가 비어 있는 적 점령지(또는 무주지): +1 (해상 이동, 특수부대 포함 부대 제외)
6. 출발 헥스가 적에 인접: +4 (이탈 비용). 해상 이동, 단독 특수부대, 적 부대가 있는 헥스로 들어가는 경우(공격) 제외
7. 철도 이동 중 비용이 국가 이동력보다 작으면 0 (혼잡 등 무시)
8. 미 해병 상륙 예외면 0

"적 인접"(ENEMY_ADJACENT)은 인접 헥스 중 부대가 있고 **점령 표시가 출발 헥스와 다른** 헥스가 있는지로 판정합니다.
(점령값 3은 예외 처리되지만 실제 데이터에는 없음)

### 3.4 적 부대가 있는 헥스 (공격 전개, 다음 작업)

비용이 불가가 아니면: 쓴 이동력 + 비용이 한도를 넘거나 목표가 바다면 100(공격 계획 표시),
아니면 OVERRUN 판정 → 실패 100, 성공이면 진입 (남은 이동력이 충분하면 비용 +1).
100을 받은 이동 루틴은 공격 계획을 세웁니다 (최소 6점 필요, 매뉴얼 3.41203). 2차 명령 단계(PHASE 3)에서는
사람 쪽 부대의 공격 계획 대신 이동이 즉시 끝납니다. → 전투 시스템 작업에서 구현합니다.

### 3.5 특수 이동

| 종류 | 조건 | 비용·효과 |
|---|---|---|
| 철도 | 철도 헥스(또는 도시)에서 시작, 적 비인접, 이번 턴 미이동, 1차 명령 단계, 그 진영의 이번 턴 철도 이동 5회 미만, 인접 철도 헥스 중 비용 0인 곳이 있음 | 철도 연결 헥스 비용 0. 시작할 때 적 차단 판정: 공산군은 `RND(1,100) < 유엔 차단 수준`(INTERDICTION, 전투 단계 DO_AIR_COMBAT가 매 턴 다시 계산: air.md 5.4), 유엔군은 공산 차단 수준이면 **선두 유닛만** UNIT_ATTRITION(25~90%). 종료 헥스에 이미 부대 2개면 멈출 수 없음. 이동 후 MOVE = 국가 이동력 (더 못 움직임), 준비도 감소 없음 |
| 해상 | 유엔군, 해안(깊은 바다 인접) 또는 바다, 미이동, 1차 명령 단계, 폭풍 아님(바다에서 시작하면 예외), 해상 수송 여유(항구 2, 육지 3, 바다 0, 총 4) | 바다 헥스 비용 0, 인접 아니어도 됨. 상륙 헥스는 확인 후 이동력 소진. 기뢰 항구 불가. 1995는 턴당 단독 미 해병 1개 |
| 공수 | UNIT_COCKED `1915:18c7`: 미군 공수(SYMBOL 3), 1950년대, 비행장 또는 일본(x 33, y 59~64), 단독, 미이동, 폭풍 아님 | 거리 무관 비용 0. 투하 손실은 매뉴얼 3.41209 |

### 3.6 미 해병 상륙 예외 (하구·저수지)

SYMBOL 12(미 해병 보병), 부대에 다른 유닛 없음, 이번 턴 이동력 미사용(MOVE = 0), 컴퓨터가 유엔군이 아님,
출발 헥스가 하구·저수지가 아님 → 하구·저수지 진입 비용 0. 그 헥스에서 멈출 수 없습니다.
하구에서 다시 하구로는 못 가고, 하구 헥스에는 점령 표시가 없어서(0) 나갈 때 인접 부대가 있으면 이탈 비용 +4가 붙습니다(원작 동작 그대로).

## 4. 되돌리기 (Move back)

원작은 걸음마다 직전 상태를 저장하고, 다음 경우에는 그 걸음을 되돌릴 수 없게 표시합니다 (`3908`~`395d`).

- 들어간 헥스가 아군 점령이 아니었음 (적 점령지·무주지 진입)
- 들어간 헥스가 정찰되지 않은(정찰 단계 0) 적 점령 헥스에 인접 (정보 "완전" 옵션이면 미적용)
- 해상·공수 이동

## 6. 매뉴얼과 코드가 다른 점

- 강: 매뉴얼은 "다리 +1, 다리 없는 강 +4"지만, 코드는 강 헥스 진입 자체에 +4(폭풍 6, 결빙 0)를 붙이고 도로 강 헥스는 고정값입니다.
- 철도 차단 손실: 매뉴얼 20~90%, 코드 `RND(25, 90)`이고 선두 유닛만 손실.
- 최소 1칸 이동, 턴 시작 이동력의 보급 의존성, 중공군 감면이 강 조합 비용에도 적용되는 점은 매뉴얼에 없습니다.
- 피란민: 매뉴얼은 "도로 무시"라고만 하지만 코드는 유엔군만 영향을 받습니다.
