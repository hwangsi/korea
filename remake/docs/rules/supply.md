# 보급 규칙 (원본 코드 기준)

원본 KOREA.EXE 디스어셈블과 매뉴얼 6.1, 6.13, 6.14, 6.2, 부록 F를 대조해 정리했습니다.
엔진은 `src/engine/supply.ts`(보급망·재보급·턴 시작 이동력)와 `src/engine/endturn.ts`(비축 수송·보충·재편성),
테스트는 `tests/turn.test.ts`입니다. 주소는 `모듈 오프셋`.

| 내용 | 위치 |
|---|---|
| 보급망 | SUPPLY.DETERMINE_SUPPLY `0252:0e96`, 중첩 시드 `0e4f`, 열 단위 확산 `0da4`, 한 칸 확산 `0ca5` |
| 재보급 | SUPPLY.REST_UP `10fa` → 본체 `01ae`(중첩), 유엔 차단 수준 `0000`, 공산군 통과 판정 `010b` |
| 턴 시작 이동력 | REST_UP 본체 `0532`~`0733` (movement.md 1장) |
| 항공 차단 약화 | OPSSUBS.EFFECTIVE_STRENGTH `0f13:0708` (air.md 2장, 엔진 `air.ts`의 `airDivisor`) |
| 비축 수송·수요 | ENDTURN.GROUND_REINFORCEMENTS `0364:06ba`~`0846` |
| 보충·재편성 | GROUND_REINFORCEMENTS `0ac0`~`1001`, 중첩 `02ff`(재편성 가능), `03ed`(재편성) |
| 도로 헥스 | HEXSTUFF.ROAD_HEX `0787:125f` |

## 1. 보급망 DETERMINE_SUPPLY

TERRAIN 바이트 2(정찰 단계)를 잠시 보급망으로 쓰고 끝나면 원래 값으로 되돌립니다. 값은 0 없음, 1 유엔, 2 공산.

1. 시드: 공산군 보급 거점 7곳 (0,22) (2,20) (7,29) (9,17) (14,10) (29,5) (33,6), 기뢰가 없는 항구 18곳(일본 6곳 포함)은 유엔,
   그리고 (33,59)를 공산 쪽으로 한 번 더 (일본 헥스라 공산군이 점령하지 않는 한 효과 없음, 원작 그대로).
   시드는 그 헥스의 점령 진영이 같을 때만 들어갑니다.
2. 확산(`0ca5`): 대상 헥스가 바다·하구·저수지가 아니고(WATERHEX 참), 대상의 점령이 그 진영이며, 출발 헥스가 이미 보급망이면 대상도 보급망.
3. 순서: **완전한 범람 채우기가 아닙니다.** 진영마다 2회 반복:
   - 유엔: 열 0→33(왼쪽 열에서), 열 33→0(오른쪽 열에서)
   - 공산: 열 33→0(오른쪽에서), 열 0→33(왼쪽에서)
   - 열 하나(`0da4`): 옆 열의 같은 행 → 옆 열의 대각 행(홀수 열은 y−1, 짝수 열은 y+1) → 같은 열 아래에서 위로(y 64→1, 출발 y+1) → 위에서 아래로(y 2→65, 출발 y−1)
   - 행 0은 확산 대상이 되지 않음
   그래서 여러 번 꺾이는 좁은 회랑은 끊긴 것으로 판정될 수 있습니다. 리메이크도 그대로 재현합니다.

검증: 기본 시나리오 3개(korea2 제외)의 모든 부대 MOVE 값이 이 보급망으로 계산한 턴 시작 이동력과 일치
(korea1 옹진 1개, korea3 1개 예외: 시나리오 제작자의 수동 값 또는 REST_UP 이후 순찰·게릴라·소해로 바뀐 점령).
korea2는 부산 교두보 미군이 준비도 75이면서 STATUS 0x40이 없는 수동 편집 상태라 제외.

## 2. 재보급 REST_UP (유닛 번호 1 → LASTUNUNIT 순서)

지도에 있는(ON_MAP) 유닛마다:

1. 진영: 번호 ≥ FIRSTUNUNIT(1950년대 156, 1995년 124)이면 유엔.
2. 회복률
   - 유엔: 10, y < 30이면 −1, 컴퓨터가 유엔이면 +2
   - 공산: 역량+7, y > 50이면 −1, 컴퓨터가 공산이면 +역량 div 2
3. STATUS = 0 (매 턴 초기화)
4. 재보급 조건: 그 헥스가 자기 진영 보급망 **그리고** 통과 판정 **그리고** `RND(1,100) ≤ 자기 비축`
   - 통과 판정(공산군만): `RND(1,100) > UNIL × y div 30`. 유엔이 서울(14,40)을 점령하고 있으면 추가로
     `RND(1,100) ≤ 50`이고 y > 41일 때 실패 (매뉴얼은 "41행 포함 남쪽"이지만 코드는 42행부터)
   - UNIL(유엔 차단 수준, 중첩 `0000`): 활동 중(도착 턴 ≤ TURN < 철수 턴)이고 임무가 차단(MISSION 2)인 항공대의
     `공대지 div 약화` 합계 div 10. 1950년대는 항공대 1~29번, 1995년은 14~34번.
     약화(EFFECTIVE_STRENGTH) = 하늘 코드(1 맑음, 2 흐림, 3 폭풍), 전천후면 1 감소(최소 1), 기지 0(일본)이고 장거리가 아니면 ×2.
     컴퓨터가 공산이면 UNIL −5 (0~95로 제한)
5. 재보급 성공: STATUS |= 0x01, 준비도 < 100이면
   - `RND(1,100) < 100 − 준비도`이고 비축 > 10이면 비축 −1 (컴퓨터 진영은 `RND(1,9) < 7`일 때만)
   - 배수: 도로 헥스(ROAD_HEX, 1950년대 폭풍이면 아님) 2, 아니면 1. 중공군은 `준비도² − 900 < RND(1,700)`이면 3, 아니면 2.
     도시 3. 유엔은 기뢰 없는 항구, 공산은 보급 거점이면 3
   - 준비도 += 회복률 × 배수
6. 실패: 유엔 유닛이고 TURN ≥ 2, (TURN ≥ 25 또는 번호 ≥ 187), 폭풍이 아니면 **공중 보급**:
   AIRLIFT_DEMAND = 1, STATUS |= 0x80 (준비도 손실 없음, 보충 없음)
7. 그 외 실패: 준비도 −5, STATUS 0x01 해제, 그 뒤 준비도 ≤ 50이고 중공군이 아니면 UNIT_ATTRITION(10%)
8. 준비도를 50~100으로 제한

그 다음 헥스마다 부대별로 턴 시작 이동력(movement.md 1장): 평균 준비도와 **헥스의 보급망**(재보급 성공 여부가 아님)으로 MOVE를 정하고,
준비도 75 이상 유닛에 STATUS 0x40.

### 매뉴얼과 다른 점

- 중공군도 보급 실패 시 준비도 5를 잃음 (매뉴얼: 손실 없음). 장비 손실만 면제
- 국군의 공중 보급은 1951년 1월 1일(25턴)부터, 그 외 유엔군(번호 187~)은 7월 8일(2턴)부터. 매뉴얼은 미군·미 해병만 2턴부터
- 서울 조건은 y > 41, 통과 판정과 비축 판정이 따로 있음 (매뉴얼은 한 식으로 설명)

## 3. 비축 수송과 수요 (GROUND_REINFORCEMENTS 06BA)

- 공산: `t = TURN div 4 + 10` (1995: 14), `+ 역량 shr 2`, 컴퓨터가 공산이면 `+ 역량 div 3`,
  1950년대에 CCF_INTERVENTION ≠ 99면 +10, CCF_INTERVENTION + 4 = TURN이면 +20.
  `STOCKPILE[0] += t − RAIL_DEMAND[0]`, RAIL_DEMAND[0] = 0
- 유엔: `u = TURN + 2` (1995: 15), 컴퓨터가 유엔이면 +1, 0~15로 제한.
  수요 = AIRLIFT(공중 보급이 있었으면 1) + SEALIFT, 폭풍이면 4로 덮어씀, + RAIL_DEMAND[1], u를 넘지 않음.
  `STOCKPILE[1] += u − 수요`
- 둘 다 1~100(1995 1~200)으로 제한
- SEALIFT_DEMAND = 바다 헥스에 있는 부대 수(다음 턴에 청구), AIRLIFT_DEMAND = 0, RAIL_DEMAND[1] = 0

STOCKPILE은 DUAL 배열 **[0] 공산, [1] 유엔** (예전 문서의 [유엔, 공산]은 잘못).

## 4. 보충 (REPLACEMENTS[국적][장비] = [턴당 보충량, 풀])

1. 풀 증가: `풀 = min(255, 풀 + 보충량)`. 미군은 TURN > 1, 미 해병 > 4, 영연방 > 8, 기타 유엔 > 15부터, 국군·북한·중공은 항상, 1995는 모두
2. 일회성 지급(1950년대, 255 제한 없이 바이트 덧셈): 4턴 미군 중형 야포 12·소총소대 18·화기소대 12, 8턴 30·45·30,
   13턴과 32턴 영연방 6·12·2, 26턴 영연방 중형 야포 18
3. 필요량: 재보급된(0x01), 제거되지 않은(0x08 없음) 지도 위 유닛의 (정원 − 보유) 합 → 비율 = 풀×100 div 필요량
4. 배분(유닛 번호 순): 부족한 장비 하나마다 `RND(1, 기회) < 비율×배수`이고 풀 > 0이면 +1, `RND(1, 배수+1) < 3`이면 풀 −1.
   기회 = 100 + 거리 보정(1950년대 중공군 y > 26이면 y − 26, 나머지 y < 38이면 38 − y), 배수 = 컴퓨터 진영 2, 아니면 1
5. 재편성: 보관 칸(1,0)의 제거된 유닛 중 가장 많은 정원 장비의 풀이 `정원 × 2 div 3`보다 **크면**
   모든 장비를 min(정원, 풀)으로 채우고 STATUS 1, 준비도 75 (경험은 BURY가 이미 신병으로). 1950년대 TF Smith(187)는 제외.
   증원 대기열에 1턴 도착으로: 미·해병·영연방·기타 유엔 → 부산(−126, 59), 국군 → 남한 도시(−188, 99), 북한 → 일반 목록(−199, 99), 중공 → (−100, 22).
   도착 처리보다 뒤에 실행되므로 실제 복귀는 다음 정리 단계

### 매뉴얼과 다른 점

- 1995 국군 보충량 4개가 매뉴얼 표와 다름 (중형 전차 33/22, 중형 야포 36/24, 기계화소대 27/12, 기계화 화기소대 8/5: 데이터/매뉴얼)
- 거리 보정, 컴퓨터 진영 배수, 번호 순 배분은 매뉴얼에 없음 (비율 배분의 실제 구현)
- 재편성 조건은 "2/3 이상"이 아니라 "2/3 초과"
- 공산 비축: 1995년은 10이 아니라 14 + 역량 shr 2. 중공군 참전 보너스 +20은 CCF+4턴(유엔 북진 후 5~8턴)이고 중국이 허세(88)면 없음
- 유엔 비축 +15는 13턴(10월 1일)에 도달. 폭풍 턴의 감소는 "−3"이 아니라 수요를 4로 덮어씀
