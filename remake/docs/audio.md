# 소리: 배경 음악과 효과음 (리메이크 추가)

원작(1992)의 소리는 PC 스피커 경고음뿐이었습니다(KOREA.TOGGLE_BEEPS, "Beeps"). 리메이크는 **그 시절 FM 사운드카드(AdLib/OPL2)
느낌의 배경 음악과 효과음**을 넣었습니다. 파일을 하나도 쓰지 않고 브라우저의 Web Audio로 그 자리에서 합성합니다.

| 파일 | 내용 |
|---|---|
| `src/audio/abc.ts` | ABC 악보 읽기(순수 로직): 조표, 임시표(마디 안 유지), 길이, 셋잇단, 부점(> <), 붙임줄, 쉼표, 화음 기호, 도돌이표 |
| `src/audio/arrange.ts` | 멜로디 + 화음 기호 → 행진 악대 편곡(순수 로직): FM 금관 멜로디, 리드 대선율, 쿵짝 베이스와 화음, 작은북·큰북·심벌, 북 굴림 전주, 마지막 화음 |
| `src/audio/synth.ts` | 악기(브라우저): 2-오퍼레이터 FM(금관·오르간·베이스), 25% 펄스파(리드), 잡음 북 |
| `src/audio/sfx.ts` | 효과음 |
| `src/audio/songs.ts` | 저장소에 들어 있는 곡(저작권이 끝난 곡)과 개인 곡 읽기 |
| `src/audio/index.ts` | 재생기: 메들리/진영별/한 곡, 설정 저장(브라우저 저장소 `conflict-korea-remake/sound`), 첫 클릭에 오디오 시작 |
| `src/ui/soundPanel.ts` | 상단 "♪" 메뉴: 음악·효과음 켜기/끄기와 음량, 곡 고르기, 다음 곡 |
| `tests/audio.test.ts` | 악보 읽기, 모든 곡의 마디 길이·음역·편곡 |

- 가사 없이 멜로디만, 화음 기호를 붙여 편곡기가 반주를 만듭니다. 모든 곡을 같은 편곡기(FM 금관·리드·쿵짝 베이스·작은북)로 돌려 같은 풍으로
  들립니다. 각 곡을 두 번(두 번째는 리드 악기를 바꿔 한 옥타브 위로) 연주합니다(나는 병사다는 짧아 세 번). 느린 곡(인터내셔널가, 전우야 잘 자라,
  전선야곡, 성스러운 전쟁)은 `solemn`(북 약하게, 화음 길게). 3/4 곡은 베이스가 첫 박, 화음이 둘째·셋째 박(왈츠식).
- 멜로디는 기억으로 쓰지 않고 공개된 악보(악보 사진, 简谱, 러시아 악보, ABC 모음)를 마디마다 옮겨 적고 다른 판본과 맞춰 봤습니다. 출처는 개인 곡이면
  `music.json`의 `sources`, 공개 곡이면 `songs.ts` 주석에 있습니다. 화음은 악보에 있으면 따랐고, 없으면 1950년대 군악대풍 기본 화음(I·IV·V)을 붙였습니다.
- 확신이 낮은 곳: 멸공의 횃불(해상도 낮은 악보 한 장, 후렴 두 성부 중 윗성부), 육군가 16분음표 몇 개, 미 공군가 "We live in fame" 부분(판본마다 다름),
  전선야곡 템포(88로 추정). 틀린 음이 들리면 `music.json`/`songs.ts`의 ABC를 고치면 됩니다.
- 저작권이 남은 곡은 **공개 저장소에 올리지 않습니다**(원본 게임 데이터와 같은 취급). `data/private/music.json`이 있으면 빌드가 standalone.html에 넣고,
  없으면 그 곡들만 빠집니다. 형식:
  `{ "songs": [{ "id", "title", "en", "credit", "side": "un"|"communist"|"any", "group": "un"|"rok"|"soviet"|"pva"|"common", "style": {...}, "abc": "X:...", "copyright", "sources" }] }`.
- 검증: 모든 곡 마디 길이·음역(MIDI 50~92)·편곡 길이(50~240초) 테스트, 브라우저 오프라인 렌더로 22곡 최대 음량 0.29~0.35(클리핑 없음, 곡마다 고름).

### 재생 방식

- **메들리(기본)**: 진영을 돌아가며 한 곡씩(국군 → 유엔군 → 소련군 → 중공군 → 공산 공통 → 국군 …, `medleyOrder`). 한 진영 곡이 몰려 나오지 않습니다.
  **진영별**: 공산군 단계에는 공산 쪽 곡(소련군·중공군·인터내셔널가), 유엔군 단계에는 유엔 쪽 곡(유엔군·국군). **한 곡**: 그 곡만 반복.
- 브라우저는 사용자가 화면을 누르기 전에는 소리를 낼 수 없어, 첫 클릭이나 키 입력 때 시작합니다.
- 백그라운드 탭에서도 끊기지 않도록 1.5초 앞까지 미리 예약합니다.

## 효과음

| 상황 | 효과음 |
|---|---|
| 부대 선택 / 목적지·공격 대상 고정 / 취소 / 되돌리기 | 짧은 신호음 |
| 일반 이동 / 철도 / 해상 / 공수 | 군화 소리 / 기관차 칙칙폭폭과 기적 / 뱃고동 / 수송기 지나가는 소리 |
| 공격 명령 / 돌파 / 공수 부대 전멸 | 나팔 / 폭발 뒤 나팔 / 폭발 |
| 전투 해결 | 총성과 포탄(전투 수에 따라) |
| 공습 | 급강하 휘파람과 폭탄 |
| 명령 단계 시작 | 유엔군: 장조 나팔, 공산군: 단조 금관과 큰북 |
| 소식 / 보고서 열기 | 텔레타이프 |
| 저장 | 차임 |
| 게임 종료 | 이긴 쪽 승리 팡파르, 진 쪽 하강 금관(두 사람이면 승자 기준) |
| 잘못된 명령 | 낮은 버저 |

검증: `__app.audio.renderOffline(id, 초)`와 `renderSfx(이름)`로 소리를 내지 않고 렌더링해 음량(최대 0.41, 클리핑 없음)을 확인했습니다.
