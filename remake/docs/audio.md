# 소리: 배경 음악과 효과음 (리메이크 추가)

원작(1992)의 소리는 PC 스피커 경고음뿐이었습니다(KOREA.TOGGLE_BEEPS, "Beeps"). 리메이크는 **그 시절 FM 사운드카드(AdLib/OPL2)
느낌의 배경 음악과 효과음**을 넣었습니다. 파일을 하나도 쓰지 않고 브라우저의 Web Audio로 그 자리에서 합성합니다.

| 파일 | 내용 |
|---|---|
| `src/audio/abc.ts` | ABC 악보 읽기(순수 로직): 조표, 임시표(마디 안 유지), 길이, 셋잇단, 부점(> <), 붙임줄, 쉼표, 화음 기호, 도돌이표 |
| `src/audio/arrange.ts` | 멜로디 + 화음 기호 → 행진 악대 편곡(순수 로직): FM 금관 멜로디, 리드 대선율, 쿵짝 베이스와 화음, 작은북·큰북·심벌, 북 굴림 전주, 마지막 화음 |
| `src/audio/synth.ts` | 악기(브라우저): 2-오퍼레이터 FM(금관·오르간·베이스), 25% 펄스파(리드), 잡음 북 |
| `src/audio/sfx.ts` | 효과음 |
| `src/audio/songs.ts` | 저장소에 들어 있는 곡(저작권이 끝난 곡)과 개인 곡 읽기 |
| `src/audio/index.ts` | 재생기: 메들리/진영별/한 곡, 설정 저장(브라우저 저장소 `conflict-korea-remake/sound`), 첫 클릭에 오디오 시작 |
| `src/ui/soundPanel.ts` | 상단 "♪" 메뉴: 음악·효과음 켜기/끄기와 음량, 곡 고르기, 다음 곡 |
| `tests/audio.test.ts` | 악보 읽기, 모든 곡의 마디 길이·음역·편곡 |

## 곡

| 곡 | 원곡 | 저작권 | 위치 |
|---|---|---|---|
| 6.25의 노래 | 김동진 작곡(1951) | **남아 있음** | `data/private/music.json` (git 제외, 이 PC에만) |
| 인터내셔널가 | 피에르 드제테르(1888), 1944년까지 소련 국가 | 만료 | `songs.ts` |
| 보기 대령 행진곡 | 케네스 앨퍼드(1914), 2차대전 영국 행진곡 | 만료 | `songs.ts` |
| 포차는 굴러간다 (The Caisson Song) | 에드먼드 그루버(1908), 미 육군가의 원곡 | 만료(1944년 미 법원) | `songs.ts` |

- 가사 없이 멜로디만, 화음 기호를 붙여 편곡기가 반주를 만듭니다. 각 곡을 두 번(두 번째는 리드 악기를 바꿔 한 옥타브 위로) 연주합니다.
- 6.25의 노래는 공개된 악보를 보고 옮겨 적었습니다. 저작권이 남아 있어 **공개 저장소에 올리지 않습니다**(원본 게임 데이터와 같은 취급).
  `data/private/music.json`이 있으면 빌드가 standalone.html에 넣고, 없으면 그 곡만 빠집니다. 형식:
  `{ "songs": [{ "id", "title", "en", "credit", "side": "un"|"communist"|"any", "style": {...}, "abc": "X:..." }] }`.
- 카튜샤·성스러운 전쟁·붉은 군대가 가장 강하다 같은 소련 행진곡은 작곡가 사후 70년이 안 됐거나(카튜샤 블란테르 1990년 사망 등) 믿을 만한
  공개 악보를 구하지 못해 넣지 않았습니다. 같은 형식으로 `data/private/music.json`에 개인용으로 추가할 수 있습니다.

### 재생 방식

- **메들리(기본)**: 모든 곡을 차례로(개인 곡이 먼저). **진영별**: 공산군 단계에는 공산 쪽 곡(인터내셔널가), 유엔군 단계에는 유엔 쪽 곡.
  **한 곡**: 그 곡만 반복.
- 브라우저는 사용자가 화면을 누르기 전에는 소리를 낼 수 없어, 첫 클릭이나 키 입력 때 시작합니다.
- 백그라운드 탭에서도 끊기지 않도록 1.5초 앞까지 미리 예약합니다.

## 효과음

| 상황 | 효과음 |
|---|---|
| 부대 선택 / 목적지·공격 대상 고정 / 취소 / 되돌리기 | 짧은 신호음 |
| 일반 이동 / 철도 / 해상 / 공수 | 군화 소리 / 기관차 칙칙폭폭과 기적 / 뱃고동 / 수송기 지나가는 소리 |
| 공격 명령 / 돌파 / 공수 부대 전멸 | 나팔 / 폭발 뒤 나팔 / 폭발 |
| 전투 해결 | 총성과 포탄(전투 수에 따라) |
| 공습 | 급강하 휘파람과 폭탄 |
| 명령 단계 시작 | 유엔군: 장조 나팔, 공산군: 단조 금관과 큰북 |
| 소식 / 보고서 열기 | 텔레타이프 |
| 저장 | 차임 |
| 게임 종료 | 이긴 쪽 승리 팡파르, 진 쪽 하강 금관(두 사람이면 승자 기준) |
| 잘못된 명령 | 낮은 버저 |

검증: `__app.audio.renderOffline(id, 초)`와 `renderSfx(이름)`로 소리를 내지 않고 렌더링해 음량(최대 0.41, 클리핑 없음)을 확인했습니다.
